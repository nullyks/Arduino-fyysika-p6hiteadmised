# Meedia- ja lahendusfailid

Selles kataloogis asuvad õppematerjalis kasutatavad pildid, ekraanitõmmised ja iseseisvate ülesannete lahendusfailid.

Piltide lisamisel tuleb kasutada kirjeldavat failinime ja õppematerjalis sisukat alternatiivteksti. Mujalt pärineva pildi juurde tuleb lisada allikas ja kasutusõigus.
